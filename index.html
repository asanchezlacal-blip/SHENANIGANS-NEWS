V1.85 [ HALLOWEEN ]

[ HALLOWEEN ]

• Added 3 new Halloween emotes.

[ GENERAL ]

• Disabled night cycle.

• Trick or Treat emote is now only usable in public servers.

[ SHOP ]

• Added 3 new emotes (Ice Cream Stand, Entertainment, Moon Leaps).

[ DISASTER PLANTS ]

MELEE:

• Base neutral melee attacks are now safe on block.

• Downslam melee attacks no longer deal damage through block and push the target back.

SPECIAL:

• Cooldown increased from 12 to 15 seconds.

• Defense Response special variant now gets canceled on hit.

• Bud Shot cooldown decrease on special reduced by 3s (7s → 4s).

• Root Swarm special variant spike now gets destroyed when you get ragdolled.

• Surging Thorns special variant now gets canceled on hit.

• Surging Thorns special variant no longer gets a damage boost for interruption.

LASSO:

• Lasso damage increased to 6.

• Lasso endlag decreased on hit.

• Lasso hitbox slightly increased in width.

ROOT SWARM:

• Root Swarm windup increased by 20%.

• Root Swarm no longer creates a trap.

• Root Swarm vertical hitbox decreased by 30%.

• Root Swarm cooldown increased to 16 seconds (15 → 16).

DEFENSE RESPONSE:

• Defense Response ground variant stun decreased.

• Defense Response cooldown increased to 18 seconds (15 → 18).

• Defense Response air variant no longer creates a trap.

• Defense Response ground variant now has melee and projectile IFrame on cast.

[ BUILD MODE ]

• Undoing now respawns all active debris.

• Undoing now makes you select the parts that have been affected.

• Temporarily disabled undoing for legacy skill blocks and character blocks.

• Added per-player undos, allowing players to undo their own changes without clashing with other builders.

[ SKILL BUILDER ]

• You can now choose to add per-branch properties.

• Clicking on a branch you already selected will now make you select the default branch.

[ BUG FIXES ]

• You can no longer drop items while emoting.

• Skin duplicates or vaulted skins are now refunded as coins.

• Fixed velocity nodes multiplying the force when multiple players are hit.

• Fixed a bug where you could get 2 of the same skin when using purchase multipliers in shop.

• fixed per branch properties not applying to the branch if run in parallel was active.
